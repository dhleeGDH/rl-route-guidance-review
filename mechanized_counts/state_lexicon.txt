# Sentence-selection lexicon for the mechanized state-form count.
#
# WHAT THIS FILE IS. The forecast-conditioned count rests on a decision rule applied to text.
# The rule itself lives in experiments/recode_state_field.py and is not restated here. What is
# fixed here is the rule's INPUT: which sentences of a study's full text the rule reads. In the
# recorded coding that input was a quotation a reader picked out. This file replaces the picking
# with a fixed vocabulary, so the input becomes reproducible from the published PDF set.
#
# HOW THE VOCABULARY WAS DERIVED. Every pattern below traces to a sentence of Section III-A,
# quoted in the comment above it. No pattern was added, dropped, or widened after any count was
# seen. The hygiene patterns in [DROP_SENTENCE] were fixed from a six-study inspection of
# extraction quality alone, before any classification was run.
#
# FORMAT. Section headers in brackets, one Python regular expression per line, case-insensitive,
# blank lines and lines opening with # ignored.

[SELECT_STATE]
# "The state s_t at decision step t contains two kinds of information." (Sec. III-A)
# "The requirement developed here concerns the information a state encodes." (Sec. III-A)
\bstates?\b
\bstate[- ](?:space|vector|representation|variables?|features?|definition)\b
\bs_?t\b
# "an observation window that learning has shaped into a predictive summary" (Sec. III-A)
# "A current observation, a time index, or a window of past observations" (Sec. III-A)
\bobservations?\b
\bobservation[- ]space\b
# "Such a forecast enters the state as a feature" (Sec. III-A)
\bfeature vectors?\b
\binput (?:vector|layer|space|features?|to the (?:network|agent|policy|actor|critic))\b

[SELECT_ROLLOUT]
# "or is generated by a model rollout at planning time" (Sec. III-A)
# "The decision-time rollout counts as predictive when its unrolling is conditioned on the
#  episode's observed state and advanced through a forecast." (Sec. III-A)
\broll-?outs?\b
\brolls? out\b
\bplanning (?:horizon|time|step)\b

[DROP_SENTENCE]
# Text hygiene. These carry a selection token without describing this study's policy state.
# The token "state" outside its technical sense.
state[- ]of[- ]the[- ]art
steady[- ]state
united states
\bwe state\b
\bas stated\b
\bstatements?\b
\bstate[- ]owned\b
