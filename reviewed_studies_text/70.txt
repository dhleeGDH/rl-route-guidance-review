Abstract—With the acceleration of urbanization and the
growth of traffic demand, traffic congestion has become more
and more prominent. In the field of path planning, Deep
Reinforcement Learning (DRL) can effectively deal with the
complex traffic environment and learn the optimal path
selection strategy. This article aims to explore the optimal path
planning algorithm based on DRL to improve the accuracy
and efficiency of path planning. The algorithm estimates the
state function by establishing a deep neural network, and uses
reinforcement learning to optimize the strategy, so as to fully
consider the actual traffic flow and provide accurate route
suggestions for users. The experimental results show that the
optimized path planning algorithm based on DRL has smaller
path-finding error and higher path-finding accuracy. After
many iterations, the routing accuracy of the algorithm can
even reach more than 96%. Therefore, the optimized path
planning algorithm based on DRL is an effective path
planning method, which can deal with complex traffic scene
information and optimize the path planning effect.

In this article, DRL is applied to the field of path
planning, and an optimized path planning algorithm based
on DRL is proposed. The algorithm estimates the state
function by establishing a deep neural network, and uses
reinforcement learning to optimize the strategy, so as to
fully consider the actual traffic flow and provide accurate
route suggestions for users. The performance and
superiority of the algorithm proposed in this article are
verified by experiments, and compared with the traditional
path planning algorithm, it is found that the method
proposed in this article has higher efficiency and accuracy
in finding the optimal path.

Keywords—Deep reinforcement learning, Traffic path
planning, Traffic flow

I. INTRODUCTION
With the acceleration of urbanization and the growth of
traffic demand, traffic congestion has become more and
more prominent, which has seriously affected people's
production and life. In order to alleviate traffic pressure and
improve the efficiency of road network, path planning has
become an important research field[1]. Traditional path
planning algorithms are mainly based on mathematical
models and optimization theory. However, these algorithms
often do not fully consider the actual traffic flow, so they
cannot provide accurate path suggestions for drivers[2]. In
recent years, DRL has made breakthroughs in many fields,
especially in the fields of games, robots and autonomous
driving. This article aims to apply DRL to the field of path
planning and design an optimized path planning algorithm
that can fully consider the actual traffic flow.

II. THEORETICAL BASIS
A. DRL
DRL is a new branch in the field of artificial intelligence.
It combines the advantages of deep learning and
reinforcement learning, deals with complex nonlinear
problems by establishing deep neural networks, and uses
reinforcement learning to optimize strategies[9]. The core
idea of DRL is to learn the optimal strategy by interacting
with the environment, and the agent can update and
optimize the strategy by constantly trying different actions
and receiving feedback from the environment.
B. Traffic path planning
Traffic path planning is an important research direction
in the field of path planning, which mainly solves the
problem of finding the optimal path in complex traffic
environment[10]. Traditional traffic path planning
algorithms are mainly based on mathematical models and
optimization theories, such as Dijkstra algorithm, A*
algorithm and genetic algorithm. These algorithms often do
not fully consider the actual traffic flow, so they cannot
provide accurate route suggestions for drivers.

DRL is a new machine learning method which combines
deep learning and reinforcement learning. It estimates the
state function by building a deep neural network and uses
reinforcement learning to optimize the strategy[3]. In the
field of path planning, DRL can effectively deal with
complex traffic environment and learn the optimal path
selection strategy[4]. In the existing research, the
application of DRL in path planning mainly focuses on two
aspects: short-distance path planning and long-distance path
planning. Short-distance path planning mainly solves the
problem of real-time path planning in dynamic traffic
environment, and it needs to provide users with the best
travel route advice quickly[5]. Long-distance route planning
is mainly concerned with providing drivers with

III. OPTIMAL PATH PLANNING ALGORITHM BASED ON DRL
In this section, an optimized path planning algorithm
based on DRL will be introduced. The algorithm combines
DRL and traffic flow data, estimates the state function by
establishing a deep neural network, and uses reinforcement
learning to optimize the strategy. The optimal path planning
algorithm based on DRL is a method to estimate the state
function by establishing a deep neural network and optimize
the strategy by using reinforcement learning. The core idea
of the algorithm is to learn the optimal strategy by
interacting with the environment, and the agent updates and
optimizes the strategy by constantly trying different actions
and receiving feedback from the environment[12]. In path
planning, agents need to choose the optimal path to reach
the target node. In order to achieve this goal, agents need to
know the structure of traffic network and traffic flow
information. By establishing a deep neural network, the
agent can encode each state in the traffic network and take
the traffic flow information as part of the input. The agent
also needs to learn a strategy, which indicates the action to
be taken in a given state. The traffic path planning model

IV. RESULT ANALYSIS AND DISCUSSION
A large quantity of interconnected network structures in
DRL model can process large-scale data in parallel and use
high-speed computing power to quickly find the global
optimal solution. According to the results of Figure 3, the
following phenomena can be observed: when the amount of
traffic scene information is small, the time required for path
planning increases with the increase of the quantity of
nodes. This may be because increasing the quantity of
nodes can not effectively improve the efficiency of path
planning in the case of less traffic scene information. In
addition, adding nodes will also increase the complexity of
calculation, which may lead to an increase in planning time.
With the increase of traffic scene information, the
advantages of multiple nodes gradually appear. This is
because, with the increase of traffic scene information,
considering more nodes can better capture the complexity
and dynamics of traffic network, so as to find a better path.
In this case, using multiple nodes for path planning can
consider the traffic situation more comprehensively and
avoid the problems of inaccurate planning or long planning
time caused by insufficient information.
